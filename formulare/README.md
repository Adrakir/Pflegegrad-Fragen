# Abrechnungsbögen Niedersachsen

Fünf eigene, leere und ausfüllbare PDF-Muster. Mit `python3 generate-billing-forms.py` reproduzierbar (reportlab, pypdf, DejaVu Sans).
Die Muster sind Erstattungsanträge/Leistungsnachweise, keine amtlichen Kassenformulare und keine Ersatzrechnungen von Einrichtungen. Kostenangaben und Summen sind selbst einzutragen; keine automatische PDF-Budgetberechnung. Unterschriften auf Papier oder nach dem von der eigenen Kasse zugelassenen Verfahren.

`Nachbarschaftshilfe_Niedersachsen_amtlich.pdf` ist das unveränderte Original des Niedersächsischen Landesamtes, abgerufen am 26.10.2026 von https://soziales.niedersachsen.de/download/184112 . Es enthält Bestätigung, Monatsabrechnung und eine nur bei Bedarf einzureichende Abtretung. Die amtliche Originalvorlage ist kein von uns erstelltes oder unter MIT neu lizenziertes Dokument. Aktuelle Version und Leistungsinhalte: https://www.ms.niedersachsen.de/startseite/gesundheit_pflege/pflege/entlastungsbetrag-und-angebote-zur-unterstutzung-im-alltag-nach-dem-sozialgesetzbuch-xi-153311.html

Keine ausgefüllten Formulare oder echten personenbezogenen Daten in dieses Repository hochladen.
